Avatar 02 · 전체 파츠 검수판

방향과 모션을 바꾸고, 프레임을 멈춰 실제 레이어 조합을 확인합니다.

제작 후보 · 최종 게임 품질 승인 전
생성 소스의 비례 차이, 소매/소품 차폐, 의상 변형과 발 접지는 추가 검수가 필요합니다. 전체 조합 자동 검사는 모든 조합의 시각적 완성도를 보장하지 않습니다.
재생과 방향
착용 파츠
브라우저의 Canvas 지원이 필요합니다.

    조합 규칙과 확인 방법
    • 모자와 헤어를 함께 착용하면 모자에 맞춘 앞/뒤 헤어 변형을 사용합니다. 해당 조합 파일이 없을 때만 헤어를 숨깁니다. 후면에서는 두피를 가리는 뒤 헤어를 몸 위에 그립니다. 긴머리 영역은 손 복원 마스크보다 앞에 유지합니다.
    • 눈 모양을 바꾸면 피부색에 맞춰 원래 눈을 가린 뒤 새 눈을 그립니다. 렌즈 색은 별도 선택입니다.
    • 뒤를 볼 때 손 소품은 몸 뒤에 가려져 숨깁니다. 마시기 외 모션의 소품 접촉은 추가 검수 대상입니다.
    • 손 앞뒤 차폐 마스크는 액세서리 전 피부/옷 조합에서 픽셀을 복원합니다.
    • 다음 프레임 버튼은 재생을 멈추고 한 칸씩 진행합니다. 격자 모드에서 방향별 발 피벗을 비교하세요.

    실행: 이 폴더에서 python -m http.server 8000 후 http://localhost:8000/preview.html에 접속하세요. 외부 서비스로 데이터를 전송하지 않습니다. 직접 file://로 열면 브라우저가 manifest 읽기를 막을 수 있습니다.
