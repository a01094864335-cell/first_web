# 소원방 PRD

## 제품과 목표

소원방은 친구들이 링크로 같은 광장에 들어와 소원 하나를 함께 응원하는 모바일 우선 웹 서비스다. 기도·절·따봉·댑 중 하나를 눌러 참여하고, 다른 사람의 동작과 말풍선을 같은 화면에서 본다. 첫 참여까지의 시간, 초대 링크 방문자의 액션 참여율, 방당 동시 참여 인원을 초기 검증 지표로 삼는다.

## MVP 사용자 흐름

1. 방장이 소원 제목을 입력해 방을 만들고 링크를 공유한다.
2. 친구가 링크를 열어 소원과 광장을 본다. 입장하면 캐릭터가 착지하고 바닥 링이 퍼진다.
3. 광장 바닥을 눌러 이동하고, 하단 네 버튼 중 하나를 눌러 동작을 시작한다. 방향키로도 이동할 수 있다.
4. 같은 버튼을 연타하면 매 탭 1점과 짧은 효과가 뜬다. 동작은 이어진다. 다른 버튼을 누르면 새 동작으로 바뀐다.
5. 채팅을 보내면 보낸 사람의 캐릭터 위에 말풍선이 뜬다. 이동하는 캐릭터를 따라가며 약 4초 뒤 사라진다.
6. 퇴장하면 캐릭터가 작은 점으로 사라지고, 다시 입장할 수 있다.

## 기능 요구사항

| 기능 | 완료 기준 |
| --- | --- |
| 방 생성·초대 | 각 방은 고유 링크와 소원 제목을 가진다. 링크를 가진 친구는 모바일 웹에서 입장할 수 있다. |
| 실시간 광장 | 같은 방 사용자의 입장·퇴장, 위치, 선택한 동작과 말풍선이 참가자 화면에 반영된다. 캐릭터는 광장 경계를 넘지 않는다. |
| 지속 동작 | 기도는 손을 모은 채 흔들리고, 절은 무릎을 꿇고 반복한다. 따봉은 자세를 버티다 팔을 바꾼다. 댑은 양팔을 접고 뒤돌아 다시 펼치며 화면 오른쪽 위를 유지한다. 이동과 채팅 중에도 마지막 동작을 이어간다. |
| 방 랭킹 | 점수는 기도·절·따봉·댑별로 방 안에서 집계한다. 탭당 1점이며 접속자가 새로 들어와도 같은 방 점수가 보인다. |
| 말풍선 | 공백 메시지는 전송하지 않는다. 최대 48자 일반 텍스트를 허용한다. 같은 사람이 다시 보내면 그 사람의 말풍선을 교체한다. |
| 모바일 조작 | 하단 액션과 채팅을 터치로 조작한다. 채팅 입력과 전송이 이동을 유발하지 않는다. 모션 줄이기 설정을 존중한다. |

## 아트 방향

크림 바닥과 세이지색 바닥 선, 코랄 착지 링과 점수 효과를 사용한다. 캐릭터는 같은 둥근 원형과 동작 프레임을 공유하고 티셔츠 색으로 구분한다. 광장에서 동시에 여러 명이 댑할 때 실루엣과 오른쪽 위 화살표가 읽혀야 한다.

## HTML 데모와 실제 서비스

이 폴더의 `plaza.html`은 단일 방 프로토타입이다. 파일 하나에 GIF에서 추출한 캐릭터 프레임을 포함한다. 같은 브라우저의 동일 출처 탭에서 입장해 이동·액션·채팅을 주고받을 수 있다. 자동 참가자와 랭킹 점수는 각 탭의 데모 데이터다.

실제 서비스에서는 방 생성과 공유 링크, 기기 간 실시간 연결, 서버의 방별 점수 저장 및 이벤트 중복 방지, 채팅 속도 제한과 신고·차단을 구현한다. 연결이 끊겼다가 돌아오면 서버의 최신 위치·참가자·점수 상태로 복구한다. 계정, 전 세계 순위, 캐릭터 꾸미기는 MVP 범위 밖이다.
